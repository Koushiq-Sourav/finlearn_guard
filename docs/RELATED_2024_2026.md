## Research gap (thesis Chapter 1-2 claim)

Nobody combines all four in one closed loop:
detection (A+B) + live push (WebSocket) + personalized teaching with voice/video (C) + finance benchmark eval (D).
- A builds detectors, no teaching.
- B detects phishing, no live classroom loop.
- C tutors, no realtime detection feed.
- D evaluates, no system.

FinLearn Guard novelty = one JSON, one DB, one server: threat -> detect -> broadcast -> guide (steps/voice/video) -> saved event -> risk visible. Offline rules + LLM gateway + safety-lock is the engineering contribution.
