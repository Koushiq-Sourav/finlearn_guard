\begin{abstract}
Finance employees routinely fall for phishing, one-time-password (OTP) scams, business email
compromise (BEC), SQL injection (SQLi), cross-site scripting (XSS) and malware lures, while
security training remains disconnected from live detection. We present FinLearn Guard, a single-server
FastAPI platform that closes the loop: threat in $\rightarrow$ hybrid detection (offline rules +
large-language-model verdict with a safety lock) $\rightarrow$ WebSocket live alert to all browsers
$\rightarrow$ personalized support guide rendered as text, voice (edge-tts) and slide video (moviepy)
$\rightarrow$ persisted event with visible risk. The detector covers a 7-kind taxonomy
(phishing, otp, bec, sqli, xss, malware, safe) with deterministic guards: score $\geq 0.6$ is never
\emph{safe} and SQLi/XSS/malware are always high severity. On a 70-case 7-kind set the hybrid reaches
binary accuracy 1.000 (F1 1.000) with kind-exact accuracy 0.943 (sqli/xss/malware/safe 10/10; all
errors confined to the phishing/otp/bec family), against a rules-only F1 of 0.929 that fails BEC
(6/10). A 1,995-row professional synthetic set (v2, disclosed) confirms pipeline scale (rules
acc.\ 0.957). No prior system combines detection, live push and multi-modal teaching in one
auditable loop; we release code, dataset builder and reproduce scripts.
\end{abstract}

\noindent\textbf{Keywords:} agentic AI; phishing detection; financial fraud; personalized tutoring;
large language models; real-time WebSocket; cybersecurity education.

\section{Introduction}
Problem: finance staff face OTP, invoice/CEO and QR lures daily; training slides are separate from
the detector, so alerts never become lessons and lessons never reflect live threats. Gap: recent
agentic detectors (SAGE \cite{sage2026}, MemoPhishAgent \cite{memophish2026}, CLASP \cite{clasp2025})
detect but do not teach; tutoring systems (SENSAI \cite{sensai2025}, SYNAPSE \cite{synapse2026},
CyberMentor \cite{cybermentor2025}) teach but ingest no live feed; benchmarks (Fraud-R1
\cite{fraudr12025}, MultiAgentFraudBench \cite{mafb2025}, Finance Agent Benchmark \cite{finagentbench2025})
evaluate but build no loop. Contribution: (1) a 7-kind safety-locked hybrid detector;
(2) a closed-loop architecture (one JSON shape, one database, one server) binding detection to
personalized text/voice/video guidance; (3) measured tables on 70 + 1,995 cases with honest
synthetic disclosure; (4) an N=30 learning-study protocol ready to run. Scope is text-borne
finance attacks; raw packet sniffing and avatar video are explicit non-goals.

\section{Methodology}
\subsection{Taxonomy} Seven kinds: \texttt{phishing} (generic lure), \texttt{otp} (OTP/vishing/QR),
\texttt{bec} (invoice/wire/CEO/gift-card), \texttt{sqli}, \texttt{xss}, \texttt{malware}
(ransomware/.exe/.apk/short-link), \texttt{safe}. Kinds drive prompts, pools and graphs.
\subsection{Closed loop} POST \texttt{/api/threats} $\rightarrow$ detector $\rightarrow$ alerter (save +
risk bump + WS broadcast \texttt{/ws/alerts}) $\rightarrow$ dashboard feed/inspector/graphs;
POST \texttt{/api/support/ask} $\rightarrow$ diagnose (screen + detect + LLM guide + scrub) $\rightarrow$
steps/voice/video saved as event. One MongoDB (Atlas) holds employees, threat\_events, devices.
\subsection{Hybrid detector} Step 1 rules: 14 regex rows $\rightarrow$ score $0..1$ + signals (offline,
$\sim$0 ms). Step 2 LLM (OpenRouter \texttt{mistralai/ministral-8b-2512}, \texttt{detector.txt}):
\texttt{\{kind, verdict, severity, reason\}}. Step 3 safety override: score $\geq 0.6$ never safe.
Step 4 medium stabilizer: mild 0.15--0.59 safe $\rightarrow$ phishing/medium; sqli/xss/malware forced
high. Missing key returns \texttt{verdict=error} (no silent fallback) by design.
\subsection{Support writer} \texttt{support.txt} + per-kind pools (self/BEC/OTP/malware/dev) with
deflection scrub (never ``contact IT''; every step self-actionable). Voice: edge-tts mp3 cached by
hash; video: moviepy slide mp4 (5 steps max) else honest slide cards.

\section{Implementation}
FastAPI + Jinja2 SSR + REST + WebSocket; MongoDB Atlas; one OpenRouter gateway
(\texttt{src/llm/client.py}); stdlib endpoint agent (register/heartbeat); navy premium UI
(Inter, inspector with danger meter, per-minute + perf graphs); pytest 3/3; Render/Docker deploy
(\texttt{live/}); 20 Simulate samples covering all 7 kinds. Reproduce (no key):
\texttt{pytest tests -q}; \texttt{python -m tests.eval\_big}.

\section{Experiments}
\subsection{Setup} Windows 11, Python 3.13 64-bit venv, local Uvicorn :8000, live OpenRouter key +
Atlas. Eval A: seed70-7kind (10/kind), full LLM. Eval-Big: \texttt{labels2000\_v2.csv} (1,995 rows,
professional full-name sentences, disclosed synthetic), 80/20 split, rules + TF-IDF centroid ML
(no LLM cost).
\subsection{Eval A results (Table~\ref{tab:a})} Hybrid binary 1.000/1.000/1.000, kind 0.943;
rules 0.886/F1 0.929 (BEC 6/10). All hybrid errors inside phishing family; sqli/xss/malware/safe
perfect. Latency: rules $\sim$0 ms, hybrid $\sim$1.3 s (free-tier LLM).

\section{Discussion}
The phishing/otp/bec overlap is the hard core: rules under-fire BEC, LLM occasionally
over-generalizes generic prize vs OTP wording. Safety-lock buys recall 1.000 at negligible FP cost
on seed70. Limits (honest): no packet sniff (REST+WS prototype), Render cold start $\sim$30 s,
slide video not avatar, English-only prompts.

\section{Conclusion and Future Work}
We delivered and measured a 6-attack closed loop with honest tables and a runnable release.
Next: real-data swap + XGBoost/SOTA baselines, N=30 study, multilingual voice, packet agent,
admin analytics. Code + builders + tables: \url{https://github.com/Koushiq-Sourav/finlearn_gurd.git}.
