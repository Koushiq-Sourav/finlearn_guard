\begin{abstract}
Phishing and OTP fraud target office users while detection and training live apart \cite{Heiding24,Koide24,Desolda24,Nair25}.
This thesis presents FinLearn Guard, one FastAPI server closing the loop: offline rules + frozen LLM verdict \cite{Koide24,Desolda24}, WebSocket live push, Support steps + voice mp3 + video mp4, plus a PC endpoint agent.
A phishing sample judges phishing/high in $\sim$1s (rules 0.0ms); voice+video renders in $\sim$6s; pytest 3/3 passes.
122 works surveyed. Gap: detectors rarely teach \cite{Koide24,Desolda24,SAGE26}, trainers rarely detect live \cite{SENSAI25,SYNAPSE26}, few ship one runnable system \cite{FraudR125,FinAgentBench25}.
Each chapter is briefed What-Why-How with running example \texttt{Urgent: verify your account http://bit.ly/otp-login}.
Chapter 4 answers: Where is agent? (Sec 4.2, four agents + paths), What is model? (Sec 4.3, rules + frozen LLM, no training), Orchestration? (Sec 4.4, REST+WS sequence + timings + failures).
\end{abstract}

\section{Introduction (briefed)}
\subsection{Background}
Electronic communication is the top fraud surface: forged logins, OTP pressure, fake invoices. Billions of spams/day \cite{Nair25} evade signatures by paraphrase, motivating semantic defences. Example: \texttt{``suspended in 2h, verify at http://bit.ly/otp-login with OTP''} needs urgency + credential + short-link read together.
\subsection{Motivation}
Detectors \cite{Heiding24,Koide24,Desolda24,UserRAG26} and tutors \cite{SchoniCHI25,Sriganthan25,TrainShield25} advance separately; joined deployable loops are rare \cite{SAGE26,FraudR125}. Personalised in-workflow lessons beat slides \cite{SchoniCHI25,TrainShield25,Pardos24}; nudges beat long content \cite{Lain24}.
\subsection{Problem Statement}
How can a small org detect phishing-like threats and teach the fix in one maintainable free-tier system? (a) 7-class detection in $\sim$1s CPU-only; (b) push to all screens; (c) steps+voice+video from same verdict; (d) tables not claims.
\subsection{Objectives}
O1 one server (pages+API+WS+media). O2 hybrid detect (rules + LLM + safety-lock score$\ge$0.6 never safe \cite{Hasan25,StruQ24}). O3 live alert. O4 3-format guide, self-actions only. O5 stdlib endpoint agent. O6 honest errors (missing key $\rightarrow$ verdict=error).
\subsection{Scope}
In: 7 text classes (phishing, otp, bec, sqli, xss, malware, safe), English, single server, free tiers. Out: packet sniffing \cite{Rigaki24,Castro25}, multilingual, longitudinal study (protocol only).
\subsection{Contributions}
C1 closed loop (one JSON/DB/server). C2 safety-locked hybrid (no training). C3 four-agent orchestration + 5-step trace. C4 honest evals (70 live + 1995 harness + N=30 protocol).
\subsection{Organization}
Ch2 122-work survey + gap; Ch3 design; Ch4 agents/model/orchestration; Ch5 build; Ch6 measure; Ch7 conclude.

\subsection{What is the model}
No trained net. Hybrid: (i) 14-row regex scorer offline 0.0ms, (ii) frozen LLM via OpenRouter default \texttt{mistralai/ministral-8b-2512}, (iii) two locks. Eval-Big centroid 1.0 is synthetic harness, disclosed overfit.
